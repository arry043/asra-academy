Version 0.1.0 · 2026-10-28 · Plan: [UAT-PLAN.md](./UAT-PLAN.md) · Report problems in: [UAT-FEEDBACK-LOG.md](./UAT-FEEDBACK-LOG.md)

> **No case has been run.** Every **Actual outcome**, **Status** and **Evidence** cell is empty until a tester fills it in on the staging environment.

## How to use this checklist

- Work through the section for your role. Each case says what to do and what you should see.
- **Actual outcome:** write what really happened in a few words ("as expected" is fine).
- **Status:** `Pass` · `Fail` · `Blocked` · `Not applicable`. If something fails, also add a line to the feedback log and write its ID here (e.g. `Fail — UAT-FB-004`).
- **Evidence:** screenshot file name or link (e.g. `STU-05-progress.png`). Hide any password before taking a screenshot.
- Use only the test accounts and test courses prepared for UAT. Never enter real card details or real student information.
- Please try the public website and the student journey on a **phone** as well as a computer, and on **Safari or Firefox** if you have them. Note the browser and device in the Actual outcome.

**Labels:** cases marked **[Needs Razorpay test keys]**, **[Needs Google Meet]** or **[Super Admin — only if approved]** are run only once that prerequisite is in place; otherwise mark them `Blocked`.
